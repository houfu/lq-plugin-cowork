## What this skill can and cannot do

There is one path here and it is the one described above: you read the document yourself, the way a lawyer reads it, and everything that follows rests on that reading. Nothing parses the file for you, so three guarantees the method was built around become things you state rather than things that were checked, and each has to be said out loud rather than glossed:

- **The calibration gate is a rule you apply to yourself.** Nothing refuses to build a deliverable when the lawyer never confirmed the colour-to-role table. So the table and their confirmation, or the absence of it, ride at the head of every artifact.
- **The page-by-page reconciliation is a reading, not a sweep.** Where you could not tell what was on a page, name the page and say the reconciliation did not run for it. Never describe a page you could not read, and never let silence stand in for a clean page.
- **The lawyer does not get their own file back with marks on it.** In its place they get the marked-passage page and, on request, the Word issues list. Say so once, plainly, at the delivery.

Two things follow from where the work happens. Everything you write lands in the session's Output folder, so name the files you leave there and say they stay; nothing here can clear them away afterwards. And the source document the lawyer attached is never written to, on either path.
