# Cover template

`cover-template.png` (1200 × 1200) is the foundation for every "My LQ Moment"
cover; the cover brief in the skill's references folder says how the two
sentences are set on it. It is supplied by the maintainer, not generated, and
is never altered, cropped, recoloured or obscured.

The cover is built as an HTML page that carries this image as its background
and opens in the preview pane. If the image does not come through into the
page, say so in one line and use the plain styled card described in the cover
brief — the same two sentences, no template image — rather than claiming a
cover that was not produced. If the file is missing altogether, say so and
give the approved text.

Practice covers use the same template and the same page, with the fixed
"Practice example — fictional training" label set above the two sentences.
