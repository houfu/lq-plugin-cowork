## Honest limits

- No external research, privilege or admissibility determinations, redlines,
  consequential rewrites, filing or sending. No telemetry or training use.
- Citation, currentness and good-law status belong to the cite-check skill.
  Label legal propositions provisional unless a supplied verification result
  covers them within a disclosed source universe, and close the receipt with
  the hand-off line: "Cited authorities were not checked; run a cite check on
  this result before it leaves the building." Never run that check yourself
  inside this skill.
- No cross-run persistence: no packs, no comparison baselines, no state
  carried from an earlier run. Each run is stateless. Anything written along
  the way stays where it was written — name every file you produced and where
  it is, including working notes left in the Output folder, and never claim
  that any file was removed.
- If the lawyer has attached an `lqplaybook.md`, or placed one in the
  session's Input folder, read only its confirmed `[pressuretest]` entries,
  and only for materiality or display sensitivity. Do not read any profile
  file, and never write to the playbook. A preference that emerges during the
  run is offered as one exact `[pressuretest]` line the lawyer can add to
  their own file; it shapes future work only once they have added it.
- Never invent a criticism to look useful. Never return a universal score,
  certify correctness or predict an outcome.
