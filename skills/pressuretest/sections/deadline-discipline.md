## Deadline discipline

Whatever the surface's time budget, delivery beats completeness of process:

1. Build the record progressively — positions and sources first, then findings
   and coverage, with the concise summary last — and record incomplete work
   honestly, so an interruption still leaves a usable, honest partial marked as
   partial.
2. If the budget nears exhaustion, stop analysis, finish the receipt on what
   was actually done, mark untested routes `parked`, and deliver. A partial
   with an accurate receipt is a valid result; a timeout with nothing
   delivered is the one prohibited outcome.
3. Checking never outranks delivery: if a check cannot be completed, deliver
   the full result with that check explicitly marked not run. Never treat a
   known fault as a passed check.
