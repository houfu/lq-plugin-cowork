## Outputs

All to the session's Output folder, never into the closing folder, each name
carrying the matter and today's date:

- **The index** — Markdown or HTML for the preview pane, and a Word document on request. One row per expected item, in the lawyer's order.
- **The status register** — an Excel workbook through the built-in Excel skill, per `references/status-register.md`.
- **The exceptions list** — missing, incomplete, conflicting, unexpected, unreadable and not-inspected items, with what would resolve each.
- **The reading notes** — per family, what was looked at, what was seen and where. A later run compares against these, which is the only reason a second run is cheaper than the first.

Name every file in the reply. Nothing written there can be deleted afterwards, so
nothing is described as temporary or cleaned up. No document in the closing
folder is renamed, moved, overwritten or altered.
