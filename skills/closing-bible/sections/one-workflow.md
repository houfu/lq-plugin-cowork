## One workflow, and what it ends with

There are no modes. Every run is the same: take stock of what the lawyer
attaches, group it, look at each family, reconcile against the expected set, and
put the result in front of them at one gate. Three things come back, and no
fourth:

| Deliverable | What it is |
|---|---|
| The index | One row per expected item, in the lawyer's order, with the version selected as final and the qualification on anything not ready. Shown in the reply, written out for the preview pane as Markdown or HTML, and as Word on request. |
| The exceptions list | What is missing, incomplete, in conflict, unreadable, not inspected or unexpected — the work list. |
| The status register | An Excel workbook, one row per expected item, with a status column and a count row whose arithmetic is on the face of it. |

Nothing is assembled. A later run writes a new dated set of the same three things
beside the old one, and the lawyer decides which they keep.
