## Workflow — a late or replaced document

A document that arrived after the last run, a replacement for one that was wrong,
or an item the lawyer has since marked `not-required`.

1. The lawyer attaches the new or replaced document **and** the register from the last run. Without the register there is no history: say so in the first reply, name what you looked for, and treat the run as a fresh reading of what is in front of you rather than reconstructing the earlier one.
2. Read the register back and say how many rows it held. Every earlier decision stands; only what changed comes back to the gate.
3. Read the affected families again, reconcile, and write a new dated register and index beside the earlier ones. Nothing is written over: the earlier files stay where they are, because nothing here can delete them and the lawyer may want both.
4. Present the change first — added, replaced with the old source named beside the new, marked not required, status changed — then the outcome line, then the files.
