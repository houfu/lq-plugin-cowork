### 7. Check the quotes before the note goes out

Before the note leaves, go back through it and find every quotation in the
supplied document again. For each one, record the provision label it lives in and
where in the file you found it. Do this even when the note is only going on
screen.

This is the one error that has no symptom. A paraphrase of a provision reads
exactly as well as the provision, so it survives your own review and the
lawyer's. If a quote fails, fix it or cut it. Never ship it with a caveat.

**Fixing a quote means changing the quote, not the formatting around it.** A
failing quotation set as a code span, in bold, or in single quotes leaves the
same words in front of the lawyer and takes them out of this check. Words of the
instrument carried outside quotation marks are a quotation with the marks taken
off, and they count as quotations here. Broadening a pinpoint until the
attribution stops looking wrong is the same move: the citation gets vaguer, the
objection goes quiet, and the note now cites a thousand words for one sentence.

Say plainly, once, that this is a check you ran on yourself. It is not an
independent verification and the note should not read as though it were. What
makes it worth something is that the lawyer can repeat it: the document is in
their own Input folder, every quote carries its provision label, and checking one
takes ten seconds. Say that in the verification record and name the file they
would open.

Record every unquoted definition, exception, scope provision, commencement
provision, annex or cross-reference the analysis depends on, with one line each
saying why. Those are what a later refresh has to watch, and they are invisible
in the note otherwise.

**The note ends with the sources.** Every source consulted, official ones kept
separate from everything else, each with the address the lawyer took it from and
the date they took it. A reader who has to ask where a quotation came from has
been handed a claim. The provenance block and the source filename go at the
bottom of every deliverable, so any quote in it is checkable against the file in
seconds.
