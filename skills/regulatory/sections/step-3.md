### 3. The publisher's own document, placed by the lawyer

The lawyer goes to the official publisher, downloads the document and puts it in
the Input folder. Those are the publisher's own bytes, moved by a human instead
of by a program, and they are the only thing this skill quotes from.

**Record the provenance block before anything is quoted.** Ask for the facts you
cannot see in the file, and print them back with it in the note and in the
verification record:

> **Source:** `CCPA-1798.82-leginfo.pdf`, placed in the Input folder
> **Publisher:** leginfo.legislature.ca.gov, the California Legislative Counsel
> **Address:** the section page the lawyer opened
> **Retrieved:** 30 August 2026, by the lawyer, from that address

That block replaces the retrieval record the original skill produced for itself,
and the difference is worth saying out loud once: it used to fetch the document,
refuse any address that redirected off the publisher's own host, and fingerprint
what came back so the same text could be shown to be identical twice. Here the
bytes are genuinely the publisher's and the lawyer attests to where they came
from. The purpose that fingerprint served — a source that does not shift
underneath the analysis — is met by the file sitting unchanged in the Input
folder for the whole session. What is gone is the independent proof, and an
answer that rests on it says so rather than implying a check that did not run.

If the block cannot be completed — no publisher named, no date, no address, or a
file whose origin the lawyer cannot vouch for — do not quote from it as official
text. Go to the delivery gate and take the provisional route.

**Then check that what arrived is what you asked for.** Publishers serve ranges
of sections on one page, and a range page is a real statute whether or not your
provision is inside it: California's group pages are cut by title, and §1798.82
sits in Title 1.81 while the adjacent group is Title 1.81.5. The host is right,
the text is real, and the provision is absent. So search the supplied file for
the number you came for before going on. If it is not there, the remedy is
another download — the individual section's own page — and the finding is about
the document, not about your reading of it.

**Four findings, kept apart.** Publisher identity, publication authority,
language and version are four independent findings, and collapsing any two of
them is how an unofficial copy comes to be labelled official.
`references/version-check.md` sets out what each one is, the site-furniture trap
that makes them look like one, and what a government-hosted convenience copy can
and cannot carry. Establish and state all four before anything is quoted.

**A rendering of a page is not the page.** If a browsing tool, a search result or
a research assistant is available in this tenant and reaches the publisher's
site, it may help the lawyer find the right address. What comes back from it is
never quoted: it is a model's version of the text, and the one rule above holds
without exception. The document in the Input folder is the source layer.
