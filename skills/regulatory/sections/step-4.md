### 4. Check the version

Read the version off the document itself and say what it is.
`references/version-check.md` says where each publisher prints it, in what words,
and what each form means. Quote the statement rather than summarising it: *"is up
to date with all changes known to be in force on or before 23 August 2026"* is a
finding; "current" is not.

If the document's own markers say this is not the text to quote — an as-enacted
page when the question is about today's law, a page listing amendments already in
force and not yet written in, a superseded consolidation — say so and ask for the
version the marker names. A caveat on a stale quote is still a stale quote. No
version statement at all is a finding too, and it blocks reliance the same way:
record it and take the provisional route rather than quoting undated words as
current law. For a dated question about superseded law, record both the date the
lawyer is asking about and the date of the text they supplied.

Then do the part no marker does for you: read the amendment list and say which of
those amendments touch the provisions this question turns on; check commencement
for the provisions you are relying on, not for the instrument; and check whether
anything you plan to quote is tagged prospective.
