## Preferences

If the lawyer has attached an `lqplaybook.md`, or placed one in the session's
Input folder, read only its confirmed `[regulatory]` entries: house citation
format, the jurisdictions they work in, and how much version detail they want on
screen. Apply them over the defaults here. If the file or the namespace is
absent, use the defaults and say nothing about it.

Read no other preference or profile file, and never write to the playbook. Where
this run settles a reusable preference, offer it as one exact `[regulatory]`
line the lawyer can paste into their own file, and leave it with them; it shapes
later work only once they have added it.

Never client-identifying facts, in any entry.
