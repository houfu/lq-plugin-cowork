## Output conventions
- The ledger is the lawyer's file. They attach it at the start of a session; the updated copy goes to the Output folder with today's date in the name. It travels with the matter, and it is the only thing that carries this work from one session to the next.
- Drafted pages, the instruction table and the cover note go to the Output folder too, named to the lawyer's pattern (`Signature Pack – [Group]` by default). Name every file when you deliver.
- Nothing written here can be deleted afterwards. Do not describe anything as cleaned up, removed or temporary; if a working file is left behind, name it so the lawyer can deal with it themselves.
- Never write onto a page a party will sign or has signed. The only marks this skill makes are on pages it drafted, before they go out, with the lawyer's approval.
- Where the lawyer wants one closing's material kept together, offer to create a folder for it and move the files there after they are written.
