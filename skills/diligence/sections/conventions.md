## Conventions

- Every artifact is stable: same inputs, same wording, sorted the same way, no
  timestamps, no absolute paths. A page rebuilt from the same register reads
  the same.
- Every page shown to the lawyer follows
  [references/review-ui.md](references/review-ui.md): state the decision in
  plain language, keep amber for the discrete item that needs attention rather
  than the whole page, support light and dark and 320px screens, keep focus
  visible, and put stable identifiers and internal mechanics in a collapsed
  technical area or the Audit view. Use **Needs a decision** for the visible
  unresolved state.
- The legaldesign skill is not part of this review. It may take a finished
  diligence result later, when the lawyer separately asks for a client-facing
  explainer. Firm branding kept in another playbook namespace never silently
  changes what this skill produces.
- A link to the original file says where the words came from; it is not the
  review experience. Every reviewed document needs the quoted passage readable
  on the page beside the finding, with enough of the clause around it to read
  it in context, and the page and clause it came from. Where a page cannot be
  read — a scan, an image, a format that did not open — it goes to a visible
  **Needs your eyes** queue with the reason, and every finding that depends on
  it is held. That never turns into **Not found** and never changes a finding
  or a ruling. This skill does not hand back the lawyer's own file with marks
  on it; say so once, plainly, rather than letting them expect it.
- A claim without its verbatim quote does not enter any artifact. Parked means
  visible, never quietly dropped.
- "Not found" is always scoped to the supplied visible text in the reviewed
  unit. It is not a claim about the whole room and does not cover missing
  materials.
- The framework is the only instruction channel. If a calibration is not a
  framework field, it does not exist — and that matters more here than it did
  upstream, because a single reader working through a room is likelier to
  absorb an instruction out of a document than a program was.
- Read carefully and slowly on substantive issue mapping, and more carefully
  still on scanned, long, dense or high-consequence material. Calibrate recall
  on the sample before scaling, as
  [references/shared/execution-modes.md](references/shared/execution-modes.md)
  sets out.
- Say which rung of reading got you the text: the document's own text layer,
  or a page you looked at as an image. An image transcription is a proposal for
  the lawyer's eyes and is labelled as one.
- Checking is by reading, and reading is fallible. Say which checks the
  original performed automatically and this run performed by reading, in those
  words, on the delivery — not only at the start.
