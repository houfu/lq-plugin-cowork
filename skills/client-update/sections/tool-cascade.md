## Tool cascade (optional)

The plain Markdown/table workflow is complete on its own. Reach for anything more only when it improves the result, and say which route you used:

1. The documents the lawyer supplies or places in the session's Input folder, read directly, plus public official sources where available.
2. A spreadsheet for reconciled matter tables, arithmetic, trends, and exception sorting, keeping source IDs beside every row and a readable static export alongside it.
3. A legal-grade licensed authority, docket, insurer, e-billing, or analytics system only when the user or firm selects it, the license permits the use, and the system's source identity, access scope, retention, and currentness are acceptable. Preserve its receipt and do not imply that licensed access alone proves the proposition.

If a route is unavailable, continue with the next safe one or state the limitation. Never upload confidential matter material merely to format or summarize it. External retrieval does not authorize sending the resulting update.

Check the numbers and the sources yourself rather than assuming something else did: confirm that every table's arithmetic adds up, that each ledger row carries a source ID and a locator, that the new report reconciles against the prior one on stable IDs, and that any chart has labels, units, an as-of date and a data table beside it. Say in the update which of those checks you actually performed and which you could not. When several matters or sources have to be covered, work through them one at a time on the same evidence fields and reconcile everything into one controlling table before drafting; more sources mean more passes, never a looser standard. Producing a formatted Word, Excel or PowerPoint version of the finished report is the relevant built-in skill's job, and it replaces neither those checks nor the lawyer's review.
