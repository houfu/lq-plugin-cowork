{{ probes | length }} question{{ "" if probes | length == 1 else "s" }} about what a harness can actually do. Each one is something a skill would like to rely on, stated so a tester can settle it in one fresh conversation with synthetic files: in Microsoft 365 Copilot Cowork by typing the prompt below, or on any harness by running the harness-probe skill, which carries out every probe, checks the result and writes a report.

A probe is not a bug report. It is a question whose answer changes what this adaptation may promise: the skills a result unlocks are named under each one, worked out from the capability codes it tests and the levels in capabilities.yaml (the Cowork cards' required and degradable capabilities). Verdicts shows what the recorded results add up to. The worst outcome is what a tester has to be ready to spot — a fluent-fake answer is a plausible reply to a thing that never happened, and it is the reason every probe says what a pass looks like before you run it.
