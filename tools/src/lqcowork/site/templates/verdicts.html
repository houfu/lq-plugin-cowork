Harness verdicts

Which skills a harness can run as intended, which run on a documented fallback, which cannot run, and which nobody has probed yet. Every verdict is computed from recorded probe results against the capability levels in capabilities.yaml, by the same engine the harness-probe skill runs.

How to add one. Install harness-probe.skill from the downloads (or point a harness at the harness-probe/ folder), ask it to probe the harness, and attach the results.json it writes to a Probe report issue. The rule is in harness-probe/references/verdict-rule.md: a skill runs as intended only when every required and every degradable capability has a passing probe, cannot run when a required one failed, and is untested while a required one has no result.
