What this is, and what it is not

It is an independent adaptation of the open-source LegalQuants skills for Copilot Cowork: the same work, rewritten for a host with no local disk, no bundled scripts and no command line, and packaged as sideloadable plugin zips.

  • It is not an official LegalQuants release, not endorsed by the upstream project, and not supported by it.
  • It is pre-release. Version {{ version }} is offered for testing, not for relying on.
  • Nothing here has been exercised in a live tenant. Every card is written against Microsoft's documentation and the capability probes below; none of it has been confirmed by running it in Cowork.

How a skill gets used

Cowork routes on the skill's description. You ask for what you want in ordinary words — "go through the tracked changes in this draft and flag what matters" — and Cowork picks the skill whose description fits. There is no slash grammar: nothing here is invoked by typing /name or $name, and a skill cannot be called by name as a command.

The conversation's Sources picker is where you steer it by hand: it lists the plugins and skills available to the conversation, so you can turn one on for a request rather than hoping the description wins. Which plugins a tenant has at all is the Microsoft 365 administrator's decision.

Because routing is a matter of wording, every card ships with trigger tests: prompts that must activate the skill, and adjacent prompts that must not. They are on each bundle's page, and in the release assets.
