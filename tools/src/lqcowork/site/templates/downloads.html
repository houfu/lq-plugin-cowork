Probe a harness

harness-probe is this repository's own skill, not an adaptation of an upstream one. Loaded on any harness with Agent Skills support, it runs the capability probes against synthetic files, checks each answer rather than trusting it, and reports which of the {{ skills | length }} skills run as intended, run on a fallback, cannot run, or are still untested. Part E of the testing guide says how to run it, and the Verdicts page judges the runs on record.
